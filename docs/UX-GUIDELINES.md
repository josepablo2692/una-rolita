# Guías de UX — Una Rolita

## Tono

Juvenil, divertido, fácil de usar. La reacción objetivo del usuario:
"qué bonito esto" — no "cómo funciona esto".

## Regla de los 3 clics

Cualquier acción principal (pedir canción, saltar cola, dejar
dedicatoria) debe alcanzarse en máximo 3 toques desde que el usuario
abre la app después de escanear el QR. Si una función necesita un
4to clic, replantear el flujo antes de construirla.

## PWA instalable

Ver ADR 0003. Debe sugerir activamente "agregar a pantalla de inicio"
/ "instalar como app de escritorio" — no depender de que el usuario
lo descubra solo en el menú del navegador.
